# Assignment #5: JavaScript Basics

Name: Mardan Khalilov  
Group: SE-2527

This project shows basic JavaScript. It has five pages with a simple menu.

## Tasks

- Task 0: Print my name and group. Show a greeting alert.
- Task 1: Use variables, math, and joined strings.
- Task 2: Change paragraph text.
- Task 3: Change a background color and font size.
- Task 4: Add and remove list items.
- Task 5: Change a box color with mouse events.
- Task 6: Show input text with a keyboard event.
- Task 7: Use a calculator with four operations.
- Task 8: Add, complete, and delete tasks.

## Technologies

HTML, CSS, and vanilla JavaScript.

## How to run

Open index.html in a web browser. No installation is needed.
Use the menu to open each page.
Press F12 and select Console to see Tasks 0 and 1.
Click Run Task 0 or Run Task 1 to run them again.
The buttons in Tasks 2 and 3 switch between two values.
Click task text on the To-Do List page to mark it as completed.
Tasks are stored in an array. They are lost when you leave or reload the page.
